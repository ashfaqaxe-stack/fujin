## Installation

```package-install
npx shadcn@latest add @fujin/otp-field
```

## Usage

```tsx
import {
  OTPField,
  OTPFieldGroup,
  OTPFieldInput,
  OTPFieldSeparator,
} from "@/components/ui/otp-field"
```

```tsx
<label htmlFor="code">Verification code</label>
<OTPField id="code" length={4} onValueComplete={verify}>
  <OTPFieldInput />
  <OTPFieldInput aria-label="Character 2 of 4" />
  <OTPFieldInput aria-label="Character 3 of 4" />
  <OTPFieldInput aria-label="Character 4 of 4" />
</OTPField>
```

Want loading, success, error and resend handled for you? Use the
[OTP Verify Card](/docs/blocks/otp-verify-card) block.

## What's different from shadcn/ui

- **Built on Base UI's OTPField**, not the `input-otp` package. Every slot is a
  real `<input>`, so the caret is native and there is no invisible overlay.
- **Paste and autofill.** Pasting a full code into any slot fills them all; the
  first slot carries `autocomplete="one-time-code"`.
- **Groups are optional.** Slots inside `OTPFieldGroup` are joined like
  shadcn's `InputOTPGroup`; slots outside a group are separate boxes.
- **40px slots with a solid focus ring** (WCAG 2.5.8 and 1.4.11).
